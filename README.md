# WLED_Scanner
[![CI](https://github.com/StefanRiese/WLED_Scanner/actions/workflows/ci.yml/badge.svg)](https://github.com/StefanRiese/WLED_Scanner/actions/workflows/ci.yml)

WLED device scanner for Windows, Linux and macOS

<img src="./WLED_Scanner.png" width="75%" height="75%">

The scanner listens on UDP port **65506** for the node announcements WLED devices broadcast,
queries each new device via `http://<ip>/json/info` and lists its name, IP, version,
architecture and uptime. Select a device and click **Open in browser** (or double-click it)
to open its web UI.

> Devices only announce themselves if *Config → WiFi Setup / Sync Interfaces → Discover nodes*
> (UDP node broadcast) is enabled in WLED. Make sure your firewall allows incoming UDP on port 65506.

The repository contains two implementations:

| Folder | Language | Platforms |
|---|---|---|
| [`wled-scanner-rs/`](wled-scanner-rs) | Rust ([egui](https://github.com/emilk/egui)) | Windows, Linux, macOS |
| [`WLED_Scanner/`](WLED_Scanner) | C# WinForms (.NET Framework) | Windows |

## Rust version

### Build

Install Rust from <https://rustup.rs>, then:

```sh
cd wled-scanner-rs
cargo build --release
```

The binary ends up in `target/release/wled-scanner` (`wled-scanner.exe` on Windows).

Linux needs the usual X11/Wayland development packages, e.g. on Debian/Ubuntu:

```sh
sudo apt install libxkbcommon-dev libgl1-mesa-dev libx11-dev libwayland-dev
```

### App icon

The window/taskbar icon is compiled into the binary on all platforms. How the executable
itself gets its icon depends on the OS:

- **Windows** – the icon is embedded into `wled-scanner.exe` automatically by `build.rs`
  (shown in Explorer and the taskbar).
- **macOS** – executables get their icon from an app bundle. Build `WLED Scanner.app`:

  ```sh
  packaging/macos/make-app.sh              # current architecture
  packaging/macos/make-app.sh --universal  # Apple Silicon + Intel
  ```

- **Linux** – the icon comes from a desktop entry. Install binary, icon and `.desktop` file:

  ```sh
  packaging/linux/install.sh               # into ~/.local
  sudo packaging/linux/install.sh /usr/local
  ```

The icon files in `assets/` are generated by `assets/make_icon.py` (requires Pillow).

### Tests

```sh
cargo test
```

### CI & releases

GitHub Actions (`.github/workflows/ci.yml`) checks formatting and Clippy, runs the tests and
builds the app on Windows, Linux and macOS for every push (all branches) and pull request. The packaged builds
(`.exe`, `.tar.gz`, macOS universal `.app` as `.zip`) are attached to each run as artifacts.
Pushing a tag like `v1.0.0` creates a GitHub release with these files.

## C# version

Open `WLED_Scanner/WLED_Scanner.sln` in Visual Studio and build. Requires .NET Framework 4.6.1 and
Newtonsoft.Json (restored via NuGet).
